## Features

- Browse PDFs from folders you choose, or open a file directly
- Search by filename, sort by name or last modified, and filter favorites
- Recent documents and reading-progress indicators
- Open PDFs from other apps (`Open with` / share)
- Native rendering with pinch zoom, swipe, go-to-page, and last-page restore
- Bookmarks, find in PDF, share, print, night mode, and password-protected files
- System, light, and dark themes (Material 3)
- First-run onboarding for folder access
